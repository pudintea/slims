APACHE
======
> sudo apt update
> sudo apt install apache2 -y
> sudo ufw allow in "Apache"

Mengaktifkan MPM EVENT
========================
> apachectl -V | grep MPM    // Cek Status apakah sudah mpm_event

> sudo systemctl stop apache2
> sudo a2dismod mpm_prefork
> sudo a2dismod mpm_worker
> sudo a2enmod mpm_event
> systemctl restart apache2

> sudo apt install libapache2-mod-fcgid -y
> sudo a2enmod proxy_fcgi setenvif // Aktifkan Modul Proxy

Untuk Cache dan Kompresi, Aktifkan mod_deflate dan mod_expires
> a2enmod deflate expires headers
> nano /etc/apache2/apache2.conf
Masukan di paling atas :
ServerName localhost

Masukan ini di paling bawah :

<IfModule mod_deflate.c>
    AddOutputFilterByType DEFLATE text/plain text/html text/xml text/css
    AddOutputFilterByType DEFLATE application/javascript application/x-javascript
</IfModule>

<IfModule mod_expires.c>
    ExpiresActive On
    ExpiresByType text/html "access plus 1 day"
    ExpiresByType image/gif "access plus 1 month"
    ExpiresByType image/jpeg "access plus 1 month"
    ExpiresByType image/png "access plus 1 month"
</IfModule>

> nano /etc/apache2/conf-available/security.conf

pilih masukan dan sesuaikan :

1. Allow for Same Origin (Default Action)

Header set X-Content-Type-Options: "nosniff"
Header set X-Frame-Options: "sameorigin"
Header set Content-Security-Policy "frame-ancestors 'self';"

# Sembunyikan versi php
Header always unset X-Powered-By
Header unset X-Powered-By
#Header set Server "secure"
Header set Server "Nginx"

# Tambahan Lagi
Header set X-XSS-Protection "1; mode=block"
Header always append X-Frame-Options DENY
Header set X-Permitted-Cross-Domain-Policies "none"
Header always set Referrer-Policy "strict-origin"

> systemctl restart apache2

PHP FPM INSTALL
==========================
> sudo apt install software-properties-common -y
> sudo add-apt-repository ppa:ondrej/php -y
> sudo apt update
> sudo apt install php8.4-fpm php8.4-mysql php8.4-gd php8.4-mbstring php8.4-curl php8.4-cgi php8.4-xsl php8.4-zip php8.4-opcache php8.4-intl php8.4-bcmath php8.4-imagick php8.4-cli php8.4-xml php8.4-common -y
> sudo systemctl status php8.4-fpm

Untuk PostgreeSQL

Jika belum running
> sudo systemctl enable php8.4-fpm

> sudo a2enconf php8.4-fpm

> cat /etc/apache2/conf-enabled/php8.4-fpm.conf

> sudo systemctl restart apache2

CEK KONFIGURASI
================
> sudo apachectl -M | grep 'mpm'
Output Anda akan seperti berikut:
mpm_event_module (shared)

Anda dapat mengulangi hal yang sama untuk proxymodul dan FastCGI:

> sudo apachectl -M | grep 'proxy'
Output akan menunjukkan:
proxy_module (shared)
proxy_fcgi_module (shared)

Aktifkan OPCache
================

> nano /etc/php/8.4/fpm/php.ini  //paling bawah posisinya

================
> sudo systemctl restart php8.4-fpm
cek status
> sudo systemctl status php8.4-fpm

> sudo systemctl restart php8.4-fpm

Downloading and Installing COMPOSER
===================================
Doc : https://www.digitalocean.com/community/tutorials/how-to-install-composer-on-ubuntu-22-04-quickstart


> cd ~
> curl -sS https://getcomposer.org/installer -o /tmp/composer-setup.php

> HASH=`curl -sS https://composer.github.io/installer.sig`
> echo $HASH

> php -r "if (hash_file('SHA384', '/tmp/composer-setup.php') === '$HASH') { echo 'Installer verified'; } else { echo 'Installer corrupt'; unlink('composer-setup.php'); } echo PHP_EOL;"
OUTPUT :
Installer verified

Jika output mengatakan Installer corrupt, Anda perlu mengunduh skrip instalasi lagi dan memeriksa ulang apakah Anda menggunakan hash yang benar.
Kemudian, ulangi proses verifikasi. Jika Anda memiliki penginstal yang terverifikasi, Anda dapat melanjutkan.

Untuk menginstal composersecara global, gunakan perintah berikut yang akan mengunduh dan menginstal Composer sebagai perintah di seluruh sistem bernama composer, di bawah /usr/local/bin:
> sudo php /tmp/composer-setup.php --install-dir=/usr/local/bin --filename=composer

> sudo apt install mariadb-server mariadb-client -y

> sudo systemctl status mariadb
> mariadb --version

AKSESS SETARA USER ROOT
===================================
Login sebagai root MariaDB
> sudo mariadb
atau
> mariadb -u root -p

Buat User
> CREATE USER 'upudin'@'localhost' IDENTIFIED BY 'rahasia';

Beri privilege setara root
> GRANT ALL PRIVILEGES ON *.* TO 'upudin'@'localhost' WITH GRANT OPTION;

Artinya:
ALL PRIVILEGES → semua hak
*.* → semua database & tabel
WITH GRANT OPTION → bisa memberi privilege ke user lain (ini yang bikin setara root)

Reload privilege
> FLUSH PRIVILEGES;
Verifikasi
> SHOW GRANTS FOR 'upudin'@'localhost';

Hasil yang benar akan mirip:
> GRANT ALL PRIVILEGES ON *.* TO 'upudin'@'localhost' WITH GRANT OPTION


Alternatif Lebih Aman (Disarankan)
===================================
Kalau tujuanmu hanya admin database tapi bukan super-root, gunakan:
GRANT ALL PRIVILEGES ON *.* TO 'upudin'@'localhost';
